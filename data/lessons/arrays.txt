## PAGE 1 [ALL]: What Is an Array?

What if you need to store 30 test scores? Thirty separate
variables would be painful.

An array is one variable that holds MANY values of the
SAME type, in numbered slots.

    index:     0     1     2     3
            +-----+-----+-----+-----+
    scores  |  90 |  85 |  70 |  95 |
            +-----+-----+-----+-----+

The numbers above are called indexes. They start at 0, not
at 1. This array has 4 elements.

## PAGE 2 [ALL]: Creating Arrays

Two common ways:

1) List the values yourself:

    int[] scores = {90, 85, 70, 95};
    String[] names = {"Ana", "Ben", "Cy"};

2) Make an empty array of a set size, then fill it:

    int[] lives = new int[3];

The [] after the type means "an array of". The size is
fixed once the array is created.

An array made with new starts with default values:

    int      ->  0
    double   ->  0.0
    boolean  ->  false
    String   ->  null  (no text yet)

## PAGE 3 [ALL]: Reading Elements

Use the index in square brackets:

    int[] scores = {90, 85, 70, 95};
    System.out.println(scores[0]);
    System.out.println(scores[2]);

Output:
    90
    70

scores[0] is the FIRST element and scores[2] is the third.

The size of an array is scores.length (no parentheses):

    System.out.println(scores.length);      prints:  4

The last valid index is always length - 1:

    System.out.println(scores[scores.length - 1]);

That prints 95.

## PAGE 4 [ALL]: Changing Elements

Assign to a slot to replace what is in it:

    int[] scores = {90, 85, 70, 95};
    scores[1] = 100;
    scores[2] += 5;

    System.out.println(scores[1]);       prints:  100
    System.out.println(scores[2]);       prints:  75

A slot can be used like any variable of its type:

    scores[0]++;                         scores[0] is now 91

You cannot make an array bigger. If you need more room,
create a new, bigger array.

## PAGE 5 [ALL]: Looping Through an Array

Arrays and loops belong together. Visit every element with
a for loop:

    int[] scores = {90, 85, 70, 95};
    for (int i = 0; i < scores.length; i++) {
        System.out.println(scores[i]);
    }

The loop runs for i = 0, 1, 2, 3. Using i < scores.length
makes sure it stops at the last element.

When you do not need the index, use the enhanced for loop:

    for (int s : scores) {
        System.out.println(s);
    }

Read it as: "for each int s in scores".
Both print 90, 85, 70, 95 (one per line).

## PAGE 6 [ALL]: Common Array Tasks

Add up all elements and find the average:

    int[] scores = {90, 85, 70, 95};
    int sum = 0;
    for (int s : scores) {
        sum += s;
    }
    double average = (double) sum / scores.length;
    System.out.println(average);         prints:  85.0

Find the largest element:

    int max = scores[0];
    for (int s : scores) {
        if (s > max) {
            max = s;
        }
    }
    System.out.println(max);             prints:  95

Start max with the first element, then replace it whenever
you meet something bigger.

## PAGE 7 [ALL]: Going Out of Bounds

Using an index that does not exist is a runtime error.

    int[] scores = {90, 85, 70};
    System.out.println(scores[3]);

Java stops with:

    ArrayIndexOutOfBoundsException:
        Index 3 out of bounds for length 3

This array has indexes 0, 1, and 2 only. Index 3 does not
exist. Negative indexes fail too.

The most common cause is <= instead of < in a loop:

    for (int i = 0; i <= scores.length; i++)   // too far

Fix: use i < scores.length.

## PAGE 8 [ALL]: Arrays Are Shared, Not Copied

Assigning one array variable to another does NOT copy the
values. Both names point to the SAME array.

    int[] a = {1, 2, 3};
    int[] b = a;
    b[0] = 99;
    System.out.println(a[0]);            prints:  99

To make a real copy, use Arrays.copyOf (you need
import java.util.Arrays; at the top of the file):

    int[] c = Arrays.copyOf(a, a.length);
    c[1] = 50;
    System.out.println(a[1]);            prints:  2

Now c is a separate array, so changing it does not
affect a.

## PAGE 9 [ALL]: The Arrays Helper Class

Java has a helper class with ready-made tools. Import it:

    import java.util.Arrays;

Print a whole array:

    int[] nums = {5, 2, 9, 1};
    System.out.println(Arrays.toString(nums));
    prints:  [5, 2, 9, 1]

Sort it from smallest to largest:

    Arrays.sort(nums);
    System.out.println(Arrays.toString(nums));
    prints:  [1, 2, 5, 9]

Printing an array directly gives something unreadable like
[I@1b6d3586. Always use Arrays.toString.

## PAGE 10 [ALL]: Two-Dimensional Arrays

An array of arrays makes a table (rows and columns).

    int[][] grid = {
        {1, 2, 3},
        {4, 5, 6}
    };

    System.out.println(grid[1][0]);      prints:  4

grid[1][0] means row 1, column 0. Rows and columns both
start at 0.

Visit every cell with nested loops:

    for (int r = 0; r < grid.length; r++) {
        for (int c = 0; c < grid[r].length; c++) {
            System.out.print(grid[r][c] + " ");
        }
        System.out.println();
    }

Output:
    1 2 3
    4 5 6

## PAGE 11 [ALL]: Common Mistakes

Using length() instead of length:

    scores.length()    // error: cannot find symbol
    scores.length      // correct (no parentheses)

(Strings are the opposite: "Ana".length() has them.)

Forgetting that the first index is 0:

    scores[1] is the SECOND element, not the first.

Trying to grow an array:

    int[] a = new int[3];
    a[3] = 7;          // runtime error, there is no slot 3

Printing an array directly instead of using
Arrays.toString.

Comparing arrays with ==. It checks whether they are the
same array, not whether the contents match. Use
Arrays.equals(a, b).

## PAGE 12 [ALL]: Recap

  - An array holds many values of the same type.
  - Indexes start at 0. The last index is length - 1.
  - {1, 2, 3} lists values. new int[5] makes 5 zeros.
  - array.length is the size (no parentheses).
  - Change a slot with array[i] = value;
  - for loops and enhanced for loops visit every element.
  - Index out of range throws
    ArrayIndexOutOfBoundsException.
  - b = a shares one array. Arrays.copyOf makes a copy.
  - Arrays.toString prints, Arrays.sort sorts.
  - int[][] makes rows and columns.
